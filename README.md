# Sleep Trace 今夜版

枕元のiPhoneを使い、夜間の音の変化を端末内で記録する実験的なWebアプリです。

## 記録するもの

- 測定開始・終了時刻
- 音イベントの時刻と強さ
- いびき候補
- 大きな音のまとまり
- 夜間環境の「静けさ」参考値

音声そのものは保存・送信しません。測定データはブラウザの `localStorage` にだけ保存されます。

## iPhoneでの使い方

1. GitHub PagesのURLをSafariで開く
2. 共有ボタンから「ホーム画面に追加」
3. アプリを開き「今夜の測定を始める」
4. マイクを許可し、最初の15秒は静かにする
5. iPhoneを充電しながら硬い枕元に置き、画面を開いたままにする
6. 朝に「起きたので測定を終了」を押す

## 制約

- 画面をロックすると、iOSがブラウザ処理を止める可能性があります。
- 実際の寝返り、心拍、血中酸素、睡眠段階は測定できません。
- いびき判定と静けさスコアは参考値で、医療診断には使えません。

## GitHub Pages

Repository Settings → Pages → Build and deployment で `Deploy from a branch` を選び、`main` / `(root)` を指定します。
